# もちあみ -持ち寄りあみだくじ-

https://mochiami.40hzp.com

選択肢も線も、みんなで持ち寄って作るあみだくじ。

## 使い方

1. トップで「あみだくじ名」と「選択肢に関するルール」を入力
2. 選択肢の数を指定（2〜30）
3. 「参加URL」「選択肢追加URL」「線追加URL」を発行して配る（QRコードの画像保存もできる）
4. 主催者画面で集まり具合を見ながら「締める」

| URL               | できること                                                                         | 見えないもの                       |
| ----------------- | ---------------------------------------------------------------------------------- | ---------------------------------- |
| 参加 `/j/…`       | 名前を入れて空いている場所に入る（1端末1人）                                       | 選択肢・他の参加者の名前           |
| 選択肢追加 `/c/…` | 選択肢を1つ出す（1端末1つ。場所は空きに自動）→「線を追加」か「線を引かない」を選ぶ | 参加者の名前と場所・他の人の選択肢 |
| 線追加 `/l/…`     | 線を1本だけ引く                                                                    | 参加者の名前と場所・選択肢         |
| 主催者 `/h/…`     | 人数の確認、締める（選択肢が指定数そろうまでは締められない）                       | 名前・選択肢・線の場所             |

線は選択肢追加URL・線追加URLを合わせて 1 端末 1 本まで。締めると全 URL の受付が終わり、全員の画面が完成したあみだくじに切り替わります。

### 線のルール

- 線は段で区切ったマス目上にだけ引ける。最初からある線と同じ高さで隣り合うマスは選べない（最初からある線に被せるのは OK）
- 同じマスに被った線は、最初からある線も 1 本と数えて、合計が奇数なら黒線（横に渡る）、偶数なら赤線（渡ってすぐ戻る＝線が無いのと同じ）。辿るときは被った本数ぶん往復する
- 追加の線どうしが同じ高さで隣り合ったら、後から送った線を 1 段下へ（埋まっていればさらに下へ）。送った人には知らせない
- 完成画面では、追加の線を送られた順に 1 本 1 秒（最後の 1 本だけ 3 秒）ズームで引き、そのあと自分の名前を辿るムービーが流れる

ルールの実装は [`public/js/amida.js`](public/js/amida.js)（サーバーとブラウザで共有）。

## 構成

- Cloudflare Workers + 静的アセット（`public/`、ビルド不要の素の JS）
- 1 つのあみだくじ = 1 つの Durable Object（SQLite ストレージ）。WebSocket（Hibernation API）で変更を即時に通知
- 端末の識別はブラウザの `localStorage` に保存したランダム ID
- データは作成から 30 日で自動削除（Durable Object の alarm）

```
src/worker.ts        HTTP API（入力チェック）と画面のルーティング
src/room.ts          Durable Object：状態の保持、役割ごとに見せる情報の制限、締め処理
public/js/amida.js   あみだくじのルール（初期線の生成・被り/ずらし・辿り）
public/js/result.js  完成画面のムービー
public/js/views/     各画面（メニュー・主催者・参加・選択肢追加・線追加）
```

## 開発

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

`npm test` はルールの単体テストと、ローカルで Worker を起動して API を確かめるテストを実行します。

## デプロイ

```bash
npm run deploy
```

`wrangler.jsonc` でカスタムドメイン `mochiami.40hzp.com` を指定しています（`40hzp.com` のゾーンが同じ Cloudflare アカウントにある前提）。
